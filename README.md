# 🐍 Python OOP Practicals

This repository contains Python programs for all **15 practicals** from the *Object Oriented Programming using Python* syllabus, along with one additional practical: a **Simple Calculator**.

The programs cover fundamental Python concepts, including conditional statements, loops, strings, lists, tuples, dictionaries, file handling, and basic problem-solving.


## 📚 Practicals List

| No. | Practical Name | Description |
|---|---|---|
| 1 | Quadratic Equation | Find the roots of a quadratic equation. |
| 2 | Prime Numbers | Check prime numbers, generate primes up to `n`, and print the first `n` primes. |
| 3 | Star Pyramid | Print a star pyramid and a reverse pyramid. |
| 4 | Character Checking | Identify letters, digits, special characters, letter case, and digit names. |
| 5 | String Operations | Find character frequency, replace characters, and remove character occurrences. |
| 6 | Swap String Characters | Swap the first `n` characters of two strings. |
| 7 | Substring Indices | Find all occurrences of a substring and return their indices. |
| 8 | Even Number Cubes | Calculate cubes of even integers using loops and list comprehension. |
| 9 | File Handling | Count characters, words, and lines; calculate character frequency; reverse word order; and separate lines into files. |
| 10 | Dictionary of Cubes | Create a dictionary using user input, allowing the user to enter keys and values and display the resulting dictionary. |
| 11 | Tuple Operations | Split tuples, select even values, concatenate tuples, and find maximum and minimum values. |
| 13 | 2D Point | Create a 2D point class and calculate the distance between points. |
| 14 | 3D Point | Demonstrate inheritance and calculate the distance between 3D points. |
| 15 | Name Validation | Validate names using exceptions and reject digits or special characters. |
| 16 | Simple Calculator | Perform addition, subtraction, multiplication, and division. |

## 🛠️ Technologies Used

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in your terminal or code editor.
4. Run a Python program using:

```bash
python practicals/01_quadratic_roots.py
```

Replace the filename with the practical you want to execute.
